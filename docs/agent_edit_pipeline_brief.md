## 1. 한 줄

사용자는 **말로만** 지시한다. 에이전트가 편집장+믹서+타이틀 디자이너로 판단하고, EDIT 도구로 잘라 붙이고 글자·소리를 얹어 **전문가가 손본 것 같은 마스터**를 프로젝트에 둔다.

생성은 Comfy. 편집은 결정론 엔진. `assemble_video` concat은 에피소드 옵션으로 남기고, **본선 마감은 EDIT** 다.

## 2. 문제 (사용자 요구)

영상을 만들 때 에이전트는 클립을 **아주 단순하게만 이어 붙인다.**  
리서치 도구(NLE·모션그래픽·합성)를 쓰면, 에이전트가 **편집까지 해서 최종본을 렌더**할 수 있어야 한다.  
그 도구는 이 팩토리에 등록되어, 미디어 작업 에이전트가 `tool_intent`로 고를 수 있어야 한다.

부족한 감각을 작업 언어로 풀면:

| 지금 되는 일 | 부족해서 거슬리는 일 |
|--------------|----------------------|
| 샷 클립 생성 (I2V / S2V) | 컷 점프, 박자 안 맞는 이음 |
| `assemble_video` concat + stem 믹스 | 디졸브, J/L컷, 오버랩, 속도 |
| `episode_subtitles` SRT / 하단 번인 | 타이틀, 하단 바, 훅 자막 모션 |
| BGM/대사 줄기를 영상 아래에 깔기 | 트랙별 페이드, 더킹, 비트 큐 |
| 업스케일 · 릴라이트 | 룩 통일 그레이드, 키/오버 합성 |

원하는 끝점: **말(길이·무드·음악·플랫폼) → 에이전트가 컷/글자/소리를 결정 → 마스터 mp4.**  
사람이 타임라인을 만지거나 “여기 0.25초 페이드”를 지시하지 않아도 된다.  
원하지 않는 끝점: T2V 한 방, 또는 사용자가 Premiere를 여는 것, 또는 에이전트가 concat만 하고 끝내는 것.

## 3. 현재 방식 (있는 것)

### 3.1 생성 본선 (유지)

GENERATE / TRANSFORM / MOTION / VOICE. Comfy. 결과물은 **프로젝트 `-o`**.  
편집 레일은 이 클립을 **소비**만 한다. I2V를 NLE로 바꾸지 않는다.

### 3.2 합본 본선 (유지, 범위 좁음)

`assemble_video` (`lib/ffmpeg_util.concat_videos` + mix):

- 에피소드 샷 순서대로 work/deliver 클립을 **일렬 concat**
- `mix_policy`로 master/BGM/대사/SFX를 **영상 아래 한 덩어리**로 믹스
- 클립 게이트(미승인 거부)
- 정규화(해상도·fps) 후 이어붙이기

없는 것: 클립 `in/out` 트림을 타임라인 좌표에 올리기, 트랙 레이어, 트랜지션, 타이틀 레이어, 룩 패스.

### 3.3 이미 겹치는 조각

| 조각 | 역할 | 편집 레일과의 관계 |
|------|------|-------------------|
| FFmpeg | 이미 합본·자막 번인 | **v1 렌더 백엔드** |
| `episode_subtitles` | 샷 누적 SRT / 하단 burn | 유지. 타이틀·훅 자막은 EDIT가 담당 |
| Blender MCP | 메쉬·일부 VFX | 3D/컴프 **v3**. 편집 NLE 아님 |
| Boogu 타이포 | **스틸** 제목 | 영상 오버레이와 별개. 카드 이미지로 쓸 수는 있음 |
| OpenMontage_full | 레시피·Remotion 참고 | **본선 연동 금지** (기존 정책). 아이디어만 |
| `shot_qa_*` | 생성 컷 QA | 편집 마스터 QA와 분리 |

### 3.4 리서치 도구가 메우는 구멍

| 리서치 | 구멍 | 이 기획에서의 위치 |
|--------|------|-------------------|
| FFmpeg | 이미 있음 | v1 컴파일러 |
| MLT / melt | 진짜 멀티트랙 NLE | **같은 JSON의 v2 백엔드** |
| Motion Canvas / Revideo | 키네틱 타이포 | **v2 타이틀 엔진** |
| Natron | 키·OCIO·OFX | **v3 합성**. Windows 비용 큼 |
| Blender 컴프 | 3D·트래킹·글로우 | 이미 MCP. 편집 선반의 기본 아님 |

리서치 문서의 “상용 품질 자율 제작이 이미 가능”은 **편집 레이어를 붙이면 마감이 올라간다**는 뜻으로 받는다. 생성 품질이 자동으로 상업 영화가 된다는 뜻은 아니다.

## 4. 목표 / 비목표

### 목표 (품질 계약)

사용자는 편집 소프트웨어를 열지 않는다. 에이전트 산출물은 아래를 **전부** 통과해야 “완료”다.

1. **편집 판단이 먼저다.** 렌더 전에 `EDIT_PLAN.md` (컷 리듬, 길이 예산, 타이틀 일, 믹스, 룩). `video-direction` Gate 7을 concat으로 끝내지 않는다.
2. **손이 느껴지는 마감:** 훅 1.5초 안, 같은 사이즈 3연속 금지, 가사 슬라이드쇼 금지, 컷이 음악/대사에 붙음, 글자 읽힘, 소리 팝/클리핑 없음.
3. 타임라인 JSON → 트림·배치·트랜지션·타이틀·오디오·최종 렌더.
4. 렌더 후 **마스터를 열고** QA. 실패하면 타임라인만 고치고 재렌더. concat을 재실행하며 끝내지 않음.
5. CLI는 미디 레일과 같게 등록. `-o` 프로젝트.
6. `assemble_video`는 에피 디버그 concat. **납품 마스터 기본 경로 = EDIT.**

말이 곧 편집 지시인 예:

- “이 클립이랑 이 곡으로 15초 쇼츠, 요즘 케이팝 뮤비처럼”
- “번안곡 커버인데 훅만 크게, 가사는 화면에 적게”
- “너무 조용해. 앞 2초를 세게 열고 중간에 숨 한번 넣어”

### 비목표 (v1)

- Natron / Docker 헤드리스 팜
- OpenMontage로 episode_pipeline 대체
- Premiere/Resolve 프로젝트 파일
- 생성 모델을 편집기로 쓰기 (T2V로 트랜지션 “그려내기”)
- 프레임마다 VLM 자동 재렌더 루프 (비용. 기존 QA와 중복)

## 5. 사용자 / 에이전트 시나리오

1. **원오프 쇼츠**: 클립 4개 + BGM + 훅 자막 2줄 → 15초 마스터.
2. **뮤비 컷**: 생성 클립을 비트에 맞춰 in/out, 크로스페이드, 곡 마스터 `music_locked`.
3. **번안 커버 MV**: I2V 클립 + 음악 마스터 + 한국어 훅 타이틀.
4. **에피소드 후처리**(옵션): `assemble_video` 대신, 같은 샷 파일을 타임라인 JSON으로 다시 자른다.

공통 입력: 이미 있는 로컬 미디어. 공통 출력: 프로젝트 폴더의 `master.mp4` + `timeline.json`.

## 7. 성공 / 실패

**성공:** 사용자가 컷 점·페이드 초를 말하지 않아도, 에이전트가 EDIT_PLAN을 쓰고 마스터를 뽑는다. 열어보면 concat 슬라이드쇼가 아니라 **자른 자리·숨·글자·소리**가 있다. 사용자가 “여기 페이드 0.25초”를 지시하지 않았다.

**실패:** 도구는 있는데 에이전트가 `from-clips`만 하고 끝냄. 또는 Natron XML을 환각으로 짬. 또는 생성 클립 품질 실패를 편집으로 “완성”이라 부름.

**정직할 것:** 전문가 손길은 **스킬(판단) + 도구(손) + 생성 클립 품질**의 곱이다. 도구만 올리면 MIDI 초안처럼 얇다. 이 기획은 판단(스킬·EDIT_PLAN·QA)을 도구와 **같은 레일**에 넣는다.

---

## 8. 제약 · 정책

- 생성 본선 = Comfy. 편집 본선 = 결정론 엔진.
- OpenMontage는 참고. 이중 지휘 금지.
- 원음 마스터 재업로드 금지 정책은 음악 레일과 동일. 편집은 **우리가 만든/가진 파일**만.
- 한국어 자막/타이틀은 폰트가 없으면 실패로 드러낸다 (네모 글자 조용히 내보내기 금지).
